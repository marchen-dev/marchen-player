## 目的

客户端访问弹弹play 代理时按与代理约定的 v1 规范为请求签名，使代理能区分自家客户端流量并在需要时拒绝未签名调用；签名不改变正常请求的结果与线路切换行为。

### 需求: 请求签名

配置了签名密钥时，客户端 MUST 为每次发往代理的 API 请求尝试附加签名参数 `_kid`、`_ts`、`_nonce`、`_sig`，签名覆盖请求方法、路径、去掉签名参数后的查询串、请求体与时间戳；签名结果 MUST 与代理侧的 v1 规范及共享测试向量完全一致。Web 与桌面端 SHALL 使用同一签名规则，仅密钥编号与密钥不同。

#### 场景: 共享测试向量

- **GIVEN** 代理提供的固定测试向量（密钥、方法、路径、查询串、请求体、时间戳、随机串）
- **WHEN** 客户端用相同输入计算签名
- **THEN** 请求体哈希、签名串与签名值和测试向量逐项一致

#### 场景: GET 请求带查询参数

- **GIVEN** 已配置签名密钥
- **WHEN** 客户端以含中文或日文关键字的查询参数请求剧集搜索
- **THEN** 发出的 URL 在原有参数之后带上 `_kid`、`_ts`、`_nonce`、`_sig`
- **AND** 代理按收到的原始查询串验签结果为有效

#### 场景: POST 请求体

- **GIVEN** 已配置签名密钥
- **WHEN** 客户端提交视频匹配请求
- **THEN** 签名覆盖实际发出的 JSON 请求体字节，请求体与签名所用内容完全相同

#### 场景: 每次尝试重新签名

- **GIVEN** 自动线路模式下主线路超时
- **WHEN** 客户端切换到备用线路重试
- **THEN** 备用线路请求使用新的时间戳与随机串重新签名

#### 场景: 不新增预检

- **WHEN** 浏览器中的 Web 版发出带签名的 GET 请求
- **THEN** 签名只出现在查询串中，不新增自定义请求头，不因签名触发额外的 CORS 预检

### 需求: 时钟偏差纠正

代理以 401 和 `signature_expired` 拒绝请求并给出服务器时间时，客户端 MUST 记录本地时钟与服务器时间的偏差，用修正后的时间重新签名并重试同一请求一次；此后同一会话内的签名 SHALL 沿用该偏差。签名相关的 401 MUST NOT 触发线路切换，重试后仍失败时按普通请求失败处理。

#### 场景: 本地时钟偏差过大

- **GIVEN** 用户电脑时间比服务器慢 10 分钟，代理处于 enforce
- **WHEN** 客户端发出请求并收到 401 `signature_expired` 与服务器时间
- **THEN** 客户端修正偏差后重签重试一次并成功
- **AND** 后续请求直接使用修正后的时间，不再先失败一次

#### 场景: 重试只发生一次

- **GIVEN** 代理持续返回 401 签名错误
- **WHEN** 客户端已经纠偏重试过一次
- **THEN** 不再重试，请求以 401 失败并按现有错误处理流程呈现

#### 场景: 其他签名错误不重试

- **WHEN** 代理返回 401 `signature_invalid`、`signature_missing` 或 `signature_unknown_kid`
- **THEN** 客户端不纠偏、不重试，也不切换线路

### 需求: 签名配置

签名密钥编号与密钥 SHALL 在构建时注入。Web 正式构建与桌面发行构建 MUST 校验二者均已配置，缺失时构建失败并只指出变量名。PR 构建、预览构建与本地开发缺少配置时 MUST 照常运行、不签名，并 SHOULD 给出一次开发者可见的提示。配置的密钥值 MUST NOT 出现在日志、遥测或错误提示中。

#### 场景: 正式构建缺少密钥

- **GIVEN** Web 正式构建或桌面发行未配置签名密钥
- **WHEN** 执行构建
- **THEN** 构建失败，错误信息只包含缺失的变量名

#### 场景: 本地开发未配置

- **GIVEN** 本地 `.env` 未配置签名变量
- **WHEN** 启动 Web 或 Electron 开发环境并发起 API 请求
- **THEN** 请求正常发出且不带签名参数
- **AND** 开发者控制台出现一次未配置签名的提示
