## 动机

Marchen 当前需要用户借助外部工具下载视频。为 Electron 增加内置 BT 下载，可将添加种子、选集、下载与现有本地播放衔接起来，同时保持影视库只随用户实际播放而更新。

## 变更内容

- Electron 左侧影视库下方新增「下载」，使用现有图标侧栏、主题、弹窗和 toast；Web 不提供入口或下载运行时。
- 支持粘贴磁力、选择/拖入 `.torrent` 和通过系统「打开方式」唤起应用；确认文件及保存目录后开始下载。
- 提供紧凑任务列表、状态筛选、名称搜索、合集文件展开、速度/进度、暂停/继续、重试、重启恢复、打开目录和删除。
- 单个选中视频完整且校验通过后允许播放；下载完成不自动播放、不自动批量入库。首次播放复用既有识别、弹幕、字幕、历史及影视库流程。
- 播放列表排除仍由下载任务管理的未完成文件；删除正在播放的文件须阻止。
- 已选文件下载完成后停止传输，保留下载期间的分片交换与上传限速设置。
- 下载记录由主进程独立持久化，视频存到用户目录；保留现有 IndexedDB 播放存储。
- 开发前验证本机 WebTorrent 的格式兼容、真正暂停、恢复、部分选集和开发态 utilityProcess；双平台安装包运行验收移至交付阶段，不阻塞本机业务与 UI 开发。未经验证的平台能力不得写成已支持。

不包含：边下边播、Web BT、系统 magnet 协议注册、RSS、资源搜索、自动追番、远程下载器、退出应用后常驻下载。

## 能力

### 新增能力

- `torrent-task-management`：任务、选集、持久化、恢复、暂停与完成即停止。
- `torrent-download-ui`：Electron 下载入口、任务列表、新建流程和设置。
- `torrent-file-open`：系统种子打开、请求排队、去重与窗口唤起。
- `download-playback-integration`：完成文件播放、延迟入库、播放列表和文件清理边界。

### 修改能力

既有播放及 IndexedDB 契约保持；新增入口的联动要求在上述能力中定义。

## 影响范围

- Main：下载服务、独立进程、任务仓库、IPC、启动/退出、文件打开与清除数据。
- Renderer：路由/侧栏、下载页、下载设置、播放器导入与目录播放列表。
- Shared：任务 DTO、事件、类型化 IPC 契约；视频 hash 与 torrent 标识保持分离。
- 构建：WebTorrent 精确版本与锁文件、下载进程产物、macOS ARM64 / Windows x64 `.torrent` 关联及安装包验证。
- 验证：可控本地种子集成测试、真实网络辅助验证、双平台安装和 UI evidence。此次只创建规划产物。
