# 第 1 轮验收报告

本轮使用真实 Electron 开发窗口和 Web 本地页面取证，验收清单只呈现维护者能直接观察的产品结果。

## 取证说明

- Electron 有历史态覆盖续播 Hero、独立导入卡、最近播放四项、进度文字和进入影视库入口。
- Web 空态确认不出现依赖本地路径的历史记录，只提供 MP4/MKV 文件选择和拖入提示。
- Web 分别切换浅色与夜间主题取证，验收后已恢复为“系统”主题偏好。
- Electron 截图包含关键帧缩略图与不同来源的最近播放封面，图片缺失时使用中性占位的行为由同一展示链路负责。

## 交互结果

- 首页导入、Hero 与最近播放均为可聚焦的原生交互元素，拖拽不是唯一入口。
- 从首页开始加载后会立即离开启动台，沿用既有 loading、waiting_user、error、ready 与 reloading 状态流。
- 历史记录缺失、路径为空或文件不可访问时会返回明确结果并显示错误反馈，不会进入半加载状态。

## 非阻塞项

- 当前主机 Node 22 低于项目声明的 Node 24；相关测试与类型检查仍通过。
- 全仓 ESLint 被工作区内相邻的弹幕碰撞与播放器回归测试文件中的既有规则错误阻断；本变更新增和修改文件的定向 ESLint 为 0 errors。
