# 第 4 轮验收报告

本轮依据维护者提供的原版截图，不再继续设计新首页，而是完整恢复旧版播放器空态。

## 恢复内容

- 恢复线框播放图标与“点击或拖拽动漫到此处播放”。
- 恢复整块提示区域点击、hover 轻微缩放和原版 drop/dragover 行为。
- 删除前三轮新增的续播、最近播放、导入按钮、卡片、分格、阴影和拖拽覆盖层。
- 恢复 Electron/Web 原有 AppShell，不保留针对 Web 新增的无侧栏布局与标题栏设置按钮。
- 首页不再读取 HISTORY 或 library；影视库已有历史续播链路保持不变。

## 取证说明

- Electron 使用真实开发窗口截图，空态与维护者提供的截图结构一致。
- Web 在真实本地页面分别截图浅色与夜间主题，完成后恢复系统主题。
- 前三轮证据保持不变，第四轮用于确认已撤回此前的首页重设计。
