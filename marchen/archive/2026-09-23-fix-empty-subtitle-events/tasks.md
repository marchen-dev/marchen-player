## 背景

幼女战记 S01E03 的两条内嵌 ASS 字幕各含 15 个显式零时长且正文为空的事件，解析器将其判为整轨错误。扫描和索引路径统一跳过此类无显示效果事件，保留缺失时长、有正文或损坏事件的错误检查。不改动其他正在进行的依赖升级。

## 1. 修复与验证

- [x] 1.1 统一扫描和索引路径对显式零时长空 ASS/SSA 事件的处理
- [x] 1.2 添加扫描、索引、异常时长边界回归并运行相关检查
- [x] 1.3 使用实际 MKV 验证两轨完整解析，记录算法可靠性评估

## 验证与评估

- 相关 13 个测试文件共 61 项通过；定向 ESLint、Web 类型检查、git diff --check 通过。
- 原始 MKV 的简日、繁日轨均成功读取并重建 741 条 ASS 事件，时间范围 0.48–1419.98 秒；每轨 15 条显式零时长空事件被跳过。结果见 evidence.json。
- 本轮未做 Electron UI 渲染验收，未提交或发布。运行环境 Node 22.22.3，仓库要求 Node 24。
- 可靠性：当前是有限格式支持的手写解复用器，具备边界检查、取消、预算与索引失败回退；不宜当成完整 MKV 支持。
- 优先审查索引完整性：当前只要取得非空索引就直接交付，缺少与完整轨道的覆盖校验。规范只是 SHOULD 为每条字幕写 CuePoint，稀疏索引可能造成静默遗漏：https://www.matroska.org/technical/cues.html 。此项为静态风险，本轮未修复。
- 时长推断缺口：缺少 BlockDuration 和 DefaultDuration 时当前报错，未实现规范定义的按显示顺序下一块时间推断：https://www.matroska.org/technical/elements.html 。本轮保留既有报错，避免超出空事件修复范围。
- 尚不支持图片、压缩/加密、独立时间缩放及 lacing 字幕；全轨读取后才交付，索引回退仍可能读过大量视频数据。
