## 动机

远程 MKV 内嵌字幕当前必须读完整条轨道、生成完整 ASS 后才能显示；索引读取内部也等待全部正文完成。真实来源曾在约 21 秒、69 次逻辑读取后仍未就绪。此前字体索引查询、8 秒回退和取消入口改善了可恢复性，没有消除正文整轨等待。

需要让当前位置字幕优先显示，并把读取调度从 React 状态管理中分离。全播放器共享缓存跨越 Renderer、解码 Worker 和原生 video，收益尚未量化，不应成为本次前置重构。

## 变更内容

- 优先验证现有 libass-wasm 的有上限事件槽位复用能力，避开已复现异常的事件删除路径；覆盖旧内容清理、样式、顺序、跳转、字号和长期资源占用，验证通过后才接入正式增量链路。
- 远程 MKV/WebM 的受支持文本字幕按播放时间范围读取、增量提交；复用字幕会话内的目录、索引及读取资源，不等待整轨正文。
- 字幕会话服务统一管理选轨、窗口、请求代次、取消、去重和预算。UI 只发送操作及展示状态，解析器不承担 UI 或网络策略。
- 索引信息不足时使用有预算的局部扫描；不能确认目标范围时明确提示并允许重试、取消和外挂导入，不静默扫描全片。
- 保持本地文件及外挂字幕现有行为、全局字号和时间偏移语义；字体失败使用默认字体，不阻塞首批正文显示。
- 按首句可显示时间、跳转后的字幕正确性、真实读取量及连续播放资源占用验收，避免以平均解码帧率替代字幕体验。

## 能力

### 新增能力

- `remote-subtitle-session`：远程字幕会话、范围读取、生命周期与可恢复状态。
- `incremental-subtitle-rendering`：增量字幕提交、样式和时间语义、渲染资源预算。

### 修改能力

无独立修改能力；本提案作为开放变更 `add-http-video-playback` 的后续优化，不修改其已签核证据或宣称修复所有播放卡顿。

## 影响范围

涉及 renderer 的 `services/media/subtitles/`、`services/player-runtime/subtitles/`、字幕平台 Port/Adapter 和字幕设置组件；需要新增范围读取、会话及渲染回归。依赖沿用当前锁定 libass-wasm；如果验证要求 fork、升级或自建 WASM，则停止生产接入并修订方案。

不新增全局缓存、跨 Worker 字节代理、新解码内核、FFmpeg/HLS、下载服务或远程外挂发现。不调整兼容内核缓冲、历史数据库结构、弹幕加载及匹配流程。适用 Electron 与 Web 桌面端，保留 Web 原有 CORS 条件。
