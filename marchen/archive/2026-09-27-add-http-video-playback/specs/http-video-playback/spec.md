## 目的

让桌面用户打开 HTTP/HTTPS 视频文件直链，复用现有播放器和弹幕功能，并明确呈现远程来源的访问限制。

### 需求: 打开视频直链

系统 SHALL 在首页提供“打开链接”，允许粘贴 HTTP/HTTPS 文件直链；MUST 通过响应及媒体探测识别内容，不仅依据地址后缀。

#### 场景: 输入合法直链

- **GIVEN** 用户拥有可访问的视频文件直链
- **WHEN** 在打开链接窗口提交地址
- **THEN** 进入可取消的加载流程，并在探测成功后播放
- **AND** 无文件扩展名但返回有效视频文件的地址同样可用

#### 场景: 输入不支持的地址

- **WHEN** 用户输入其他协议、网页地址或 m3u8/HLS、DASH 清单
- **THEN** 系统拒绝不支持的输入或内容，并保留输入便于修改
- **AND** 不解析网页、不启用直播或播放清单处理

### 需求: 按范围读取与重定向

系统 MUST 仅按需获取有限范围的数据，验证远端实际支持范围读取且总长度可确定；SHALL 支持有限次 HTTP/HTTPS 重定向。

#### 场景: 支持范围读取的视频服务

- **GIVEN** 服务器返回有效的范围响应和文件总长度
- **WHEN** 打开视频并跳转进度
- **THEN** 按播放和探测需要获取对应数据，不要求先下载整片
- **AND** 服务器拒绝 HEAD 或没有 ETag 本身不构成拒绝播放的理由

#### 场景: 忽略范围请求或无限重定向

- **WHEN** 服务返回整片响应、无效范围、未知总长度或超过重定向上限
- **THEN** 停止继续读取并说明不支持该来源或重定向失败
- **AND** 不把整片响应缓冲到内存或写成本地临时视频

### 需求: 双端访问与播放能力

系统 SHALL 在 Electron 与 Web 复用现有原生/兼容播放能力；Web 必须遵守浏览器跨域及混合内容规则。

#### 场景: Electron 打开局域网视频

- **GIVEN** 用户主动输入局域网 NAS 的可访问 HTTP 文件直链
- **WHEN** 提交地址并通过媒体探测
- **THEN** 可通过桌面应用播放，不以浏览器 CORS 缺失作为直接拒绝条件

#### 场景: Web 来源不允许读取

- **GIVEN** 来源没有允许必要的跨域读取，或 HTTPS 页面只能得到纯 HTTP 视频
- **WHEN** 请求被浏览器阻止
- **THEN** 显示可理解的访问失败提示及检查 HTTPS/跨域配置的建议，不错误宣称编码不支持
- **AND** 无法区分跨域与网络故障时不武断断言具体原因

#### 场景: 兼容内核与媒体功能

- **GIVEN** 直链返回现有内核能够解码的容器和编码
- **WHEN** 播放、切换支持的音轨、选择支持的内嵌字幕或使用截图/预览
- **THEN** 使用同一网络来源完成操作，保持既有能力边界
- **AND** 不尝试扫描远端目录寻找下一集、外挂字幕或字体

### 需求: 弹幕匹配独立降级

系统 SHALL 尝试使用真实文件前缀 MD5、总大小及名称匹配弹幕；MUST NOT 将 URL 摘要或观看记录标识当作文件 MD5。

#### 场景: 可获取匹配信息

- **GIVEN** 已取得完整大小和前 min(16 MiB, 文件大小) 字节
- **WHEN** 自动匹配
- **THEN** 按现有文件匹配口径提交，并沿用直接播放、失败重试和手动匹配操作

#### 场景: 匹配信息不足或请求失败

- **GIVEN** 视频可读取但无法在有限时间内取得匹配所需信息，或匹配服务失败
- **WHEN** 用户选择直接播放或手动匹配
- **THEN** 仍可继续观看，失败不会被伪装成媒体解码失败
- **AND** 播放中补充弹幕不重开视频、不跳进度、不改变暂停状态

### 需求: 网络恢复和取消

系统 MUST 对读取设置有限超时、重试及缓存预算；取消、切换来源或更换链接后旧结果不得影响新会话。

#### 场景: 播放中断网或链接失效

- **WHEN** 数据读取持续失败或服务返回拒绝访问
- **THEN** 保留已记录进度，显示重试或更换链接的入口
- **AND** 不无限等待，不根据单次 403 就断定链接已经过期

#### 场景: 快速切换视频

- **GIVEN** 视频 A 的探测、范围读取或弹幕请求尚未结束
- **WHEN** 用户打开视频 B 或取消
- **THEN** A 的读取被取消或结果被忽略，不能覆盖 B 的画面、弹幕、进度及错误提示

### 需求: 访问地址的使用边界

系统 MUST 将网络访问限定为用户提交的 HTTP/HTTPS 媒体及其受限重定向，保留现有文件访问隔离；默认不附带应用已有登录凭证。

#### 场景: 签名链接与不支持的鉴权

- **GIVEN** 用户输入带查询签名的直链
- **WHEN** 播放和保存记录
- **THEN** 请求保留原始签名语义，日志与遥测不包含完整地址、查询凭证或重定向凭证
- **AND** 来源若要求额外登录或自定义请求头，显示当前不支持，不读取其他应用的 Cookie
