# HTTP 文件直链播放 — 第一轮

实现首页打开链接、匿名范围读取、桌面受控网络租约、远程来源身份与历史、同内容换链接、网络错误恢复、现有双内核和字幕/弹幕接入。m3u8/HLS、DASH、网页解析、登录、自定义请求头与下载不在本次范围。

## 证据与样片

真实读取本机受控 HTTP 服务 1188/1189：90 秒 H.264 MP4；20 秒 H.264 MKV、两条 AAC 音轨、内嵌 SRT。支持 Range、HEAD 405、无 ETag；提供 302、403、无 CORS、无 Range、延迟响应与不同内容。所有页面证据来自实际播放器，没有替换播放器画面。弹幕 API 使用受控匹配与评论响应；未宣称实际弹幕服务在线可用。全屏错误入口通过注入运行时错误验证，链接输入、焦点和容器操作为真实 UI。音轨切换检查状态与播放，不冒充人工听音。

Web 与 Electron 实测原生首帧、30 秒 seek/暂停、替换链接续播；兼容 MKV 实测首帧、5 秒 seek、第二音轨、字幕、暂停状态下弹幕更新、截图及预览。慢探测取消后仍为 idle；内容核对失败保留旧记录地址。

## 技术检查

Node 24.20.0：main 22 文件/107 测试、player-loading 4 文件/35 测试、player-runtime 40 文件/193 测试通过。类型检查通过；定向 ESLint 无错误，5 条 React 提示（其中 1 条是既有 runtime 的 effect 提示）。Electron 和 Web 构建通过，构建保留已有动态 import/chunk 大小提示。未打包安装包、签名、公证或部署。

回归包含本地租约/导航撤销、历史恢复、操作代次、同记录持久化顺序、远程真 hash 与记录键分离、前缀失败降级、有限重试、队列取消、ETag 变化、非法跳转与重定向上限。不会将本机短样片测试推广为全平台兼容结论。

## 限制与设计偏离

- 第一版只接受 HTTP/HTTPS 视频文件且必须提供正确的范围响应及已知总长度；Web 需要匿名 CORS 和可读的 Content-Range。HTTPS 页面不能播放普通 HTTP 地址。Electron 不继承浏览器登录 Cookie。
- 替换链接按前 min(16 MiB,size) 的 MD5 加完整大小核对，非全文件内容证明。没有可比较指纹时只能作为新视频打开；无版本响应头时不能完全检测会话内同大小内容替换。
- 每个 JS 范围读取实例最多 2 个并发、单读及缓存 32 MiB；请求 15 秒、瞬时错误最多重试 2 次，前缀识别 30 秒。复用原有预览队列，不新增全片预扫描。多个独立读取实例/Worker 与原生 video 的浏览器缓冲并非播放器全局 32 MiB/2 并发上限；尚无跨消费者抢占式网络调度，属于本轮预算设计的收敛。
- 明确的网络访问失败保留来源错误语义；浏览器原生媒体错误存在格式/网络原因不透明的情况，不能保证所有上游异常都可准确归因。
- 未验证 Windows、Linux、Safari、实际 NAS/网盘、复杂公网重定向、弱网长时播放、远程大文件 HEVC/ASS 字体和全部编码组合。原始访问地址按需求保存在本机历史；遥测对 HTTP 地址路径/查询脱敏。
- 仓库同时出现流程技能和项目配置变更，本次没有修改或回退这些并行工作。
