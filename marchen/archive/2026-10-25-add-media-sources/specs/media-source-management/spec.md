## 目的

让桌面端用户在应用内添加、维护和移除 WebDAV、Jellyfin、Emby 媒体源，并在本机保存访问凭证。

### 需求: 媒体源入口只在桌面端提供

系统 SHALL 只在 Electron 桌面端的侧栏显示「媒体源」tab，位置在「影视库」和「下载」之间。Web 端 MUST NOT 显示该入口；直接访问对应地址时 MUST 重定向到视频播放页。

#### 场景: 桌面端显示入口

- **GIVEN** 用户使用桌面端
- **WHEN** 应用启动
- **THEN** 侧栏在「影视库」之后、「下载」之前显示「媒体源」

#### 场景: Web 端访问媒体源地址

- **GIVEN** 用户使用 Web 端
- **WHEN** 用户手动访问媒体源页面地址
- **THEN** 页面重定向到视频播放页

### 需求: 添加媒体源

系统 SHALL 允许用户选择 WebDAV、Jellyfin 或 Emby 类型，并填写名称、服务器地址、用户名和密码来添加媒体源。保存前 MUST 先通过连接测试；测试失败时 MUST 显示可以理解的失败原因，并且不保存该来源。

#### 场景: 连接测试成功后保存

- **GIVEN** 用户填写了可访问的 Jellyfin 地址和正确的账号密码
- **WHEN** 用户点击保存
- **THEN** 系统先完成连接测试，再保存该来源
- **AND** 来源总览中出现这张来源卡片

#### 场景: 账号密码错误

- **GIVEN** 用户填写的 WebDAV 密码错误
- **WHEN** 用户点击测试连接或保存
- **THEN** 系统提示账号或密码错误
- **AND** 不保存该来源

#### 场景: 地址无法访问

- **GIVEN** 用户填写的服务器地址无法连接
- **WHEN** 测试连接超时或失败
- **THEN** 系统提示无法连接服务器，用户可以修改地址后重试

#### 场景: 地址格式无效

- **GIVEN** 用户填写的地址不是 HTTP 或 HTTPS 地址
- **WHEN** 用户尝试测试连接
- **THEN** 系统直接提示地址无效，不发起网络请求

### 需求: 凭证保存

系统 SHALL 把凭证直接保存在本机的应用数据目录中，不依赖操作系统的加密或密钥环能力，所有平台的行为一致。Jellyfin 和 Emby 登录成功后 MUST 只保存服务器返回的访问令牌，不保存密码；WebDAV 保存用户名和密码。界面层 MUST NOT 读取到凭证，凭证 MUST NOT 写入播放记录、日志或遥测事件。

#### 场景: Jellyfin 不保存密码

- **GIVEN** 用户用账号密码成功添加了 Jellyfin 来源
- **WHEN** 系统保存该来源
- **THEN** 持久化内容中只有访问令牌，没有密码

#### 场景: 没有系统密钥环的 Linux

- **GIVEN** 用户使用没有配置系统密钥环的 Linux 桌面
- **WHEN** 用户添加 WebDAV 来源
- **THEN** 来源正常保存，重启应用后仍然可用

### 需求: 来源总览

系统 SHALL 以卡片网格展示所有媒体源，每张卡片显示名称、类型、地址摘要和连接状态。没有来源时 MUST 显示空态说明和「添加媒体源」按钮。

#### 场景: 没有任何来源

- **GIVEN** 用户没有添加过媒体源
- **WHEN** 用户打开媒体源 tab
- **THEN** 页面显示空态说明和「添加媒体源」按钮

#### 场景: 某个来源连接失败

- **GIVEN** 用户有两个来源，其中一个服务器离线
- **WHEN** 用户打开媒体源 tab
- **THEN** 离线来源的卡片显示连接失败状态和重试入口
- **AND** 另一个来源不受影响，仍然可以正常进入

### 需求: 编辑、重新登录与移除

系统 SHALL 通过来源卡片的右键菜单提供编辑、重新登录和移除操作。编辑地址或账号后 MUST 重新通过连接测试才能保存。移除 MUST 先让用户确认，并同时删除该来源的凭证；已有的播放记录 MUST 保留。

#### 场景: 移除来源

- **GIVEN** 用户有一个播放过视频的 WebDAV 来源
- **WHEN** 用户在右键菜单中选择移除并确认
- **THEN** 来源卡片和对应凭证被删除
- **AND** 该来源产生的播放记录仍然留在播放记录和影视库中

#### 场景: 取消移除

- **GIVEN** 用户在右键菜单中选择了移除
- **WHEN** 用户在确认框中点击取消
- **THEN** 来源保持不变

### 需求: 重置应用时清除媒体源

用户在设置中重置应用时，系统 SHALL 删除全部媒体源配置和凭证，以及每个来源记住的浏览位置，并结束这些来源正在使用的连接。重置完成后，媒体源 tab MUST 显示空态。

#### 场景: 重置后媒体源清空

- **GIVEN** 用户添加过一个 Jellyfin 来源和一个 WebDAV 来源
- **WHEN** 用户在设置中重置应用
- **THEN** 媒体源 tab 显示空态
- **AND** 本机不再保存这两个来源的地址、账号、密码和访问令牌

#### 场景: 播放中重置

- **GIVEN** 用户正在播放某个媒体源里的视频
- **WHEN** 用户重置应用
- **THEN** 该来源的连接被关闭，重置后不能再用旧凭证访问服务器

#### 场景: 删除配置失败

- **GIVEN** 媒体源配置文件因为权限问题无法删除
- **WHEN** 用户重置应用
- **THEN** 系统提示重置失败，不会让界面显示为已经清空

### 需求: 登录失效处理

当服务器返回未授权时，系统 SHALL 把该来源标记为需要重新登录，并引导用户重新输入凭证；系统 MUST NOT 无限重试，也 MUST NOT 自动删除该来源。

#### 场景: Jellyfin 令牌被吊销

- **GIVEN** 用户在 Jellyfin 后台注销了本应用的设备
- **WHEN** 用户进入该来源浏览
- **THEN** 系统提示登录已失效，并提供重新登录入口
- **AND** 重新登录成功后，回到用户原来要进入的位置
