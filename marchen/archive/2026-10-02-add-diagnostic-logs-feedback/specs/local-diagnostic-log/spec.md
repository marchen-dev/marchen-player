## 目的

在桌面端持续记录可用于排障的本地诊断日志，覆盖失败、关键播放链路与运行环境，并保证体积有上限、不影响业务流程。

### 需求: 日志始终开启且不影响业务

桌面端 SHALL 在遥测关闭、Sentry 未配置或初始化失败时仍记录本地日志；日志写入失败 MUST 静默降级，不得中断业务，也不得再通过遥测上报自身失败。

#### 场景: 遥测关闭时仍记录

- **GIVEN** 遥测处于关闭状态
- **WHEN** 用户导入视频且播放失败
- **THEN** 本地日志中包含该次导入与失败记录

#### 场景: 日志目录不可写

- **GIVEN** 日志目录无写入权限
- **WHEN** 应用产生日志
- **THEN** 应用正常运行，不出现错误弹窗或崩溃

### 需求: 记录失败与异常

系统 MUST 记录：主进程与渲染进程的未捕获异常和未处理拒绝、渲染进程及子进程异常退出（含原因与退出码）、窗口无响应与恢复、页面加载失败、显式上报的错误（含错误码）、以及导入 / 播放 / 字幕 / 下载 / 远程导入失败事件。

#### 场景: 渲染进程崩溃

- **WHEN** 渲染进程异常退出
- **THEN** 日志中出现一条 error 记录，包含退出原因与退出码

#### 场景: 未处理的 Promise 拒绝

- **WHEN** 渲染层出现未处理的 Promise 拒绝
- **THEN** 日志中出现对应 error 记录，包含错误消息与堆栈

### 需求: 记录关键播放链路

系统 SHALL 以 info 级别记录一次播放从导入、识别匹配、弹幕加载、媒体准备、内核切换、首帧、显著卡顿到结束的节点，同一次操作的记录 MUST 带有相同的操作关联 ID；系统 MUST NOT 记录逐秒进度、单条弹幕或字幕正文。

#### 场景: 串联一次播放

- **WHEN** 用户导入并成功播放一个视频
- **THEN** 日志中按时间顺序出现导入开始、媒体准备完成、播放开始等记录，且共享同一个操作 ID

### 需求: 启动环境快照

每次启动 SHALL 写入一条环境快照：应用版本与构建信息、系统与架构、GPU 功能状态、兼容内核支持情况与关键播放设置；公共构建信息 SHOULD 只在快照中出现，不在每条记录中重复。

#### 场景: 启动写入快照

- **WHEN** 应用启动完成
- **THEN** 日志中新增一条包含版本、系统、GPU 状态的快照记录

### 需求: 结构化格式

每条日志 MUST 为单行可解析的结构化记录，包含时间、级别、来源进程、分类与消息；第三方组件写入的纯文本 MUST 被包装为合法记录而非破坏格式。时间 MUST 以日志产生时刻为准。

#### 场景: 更新器写入纯文本

- **WHEN** 自动更新组件输出一行纯文本日志
- **THEN** 该行被记录为分类为更新器的合法结构化记录

### 需求: 体积受控

日志总量 MUST 不超过约 15 MB：单文件达到上限后轮转，最多保留当前文件与两份历史；同一错误短时间内大量重复时 MUST 合并为计数记录；单条记录 MUST 有长度上限；info 级别 SHALL 限流，warn / error 不限流。

#### 场景: 达到单文件上限

- **GIVEN** 当前日志文件接近上限
- **WHEN** 继续写入
- **THEN** 当前文件成为历史文件，最旧的历史文件被删除，新记录写入新文件

#### 场景: 错误刷屏

- **GIVEN** 某错误在 10 秒内重复数百次
- **WHEN** 时间窗口结束
- **THEN** 日志中只保留前几条与一条带重复次数的汇总记录

#### 场景: 退出前汇总不丢失

- **GIVEN** 合并窗口尚未结束
- **WHEN** 用户退出应用
- **THEN** 汇总记录在退出前写入

### 需求: 目录与生命周期

正式版日志 SHALL 存放在系统惯用日志目录（macOS `~/Library/Logs/Marchen`），开发版 MUST 使用独立目录不与正式版混写；旧版日志目录 SHOULD 在首次启动时移除；重置应用 MUST 清空日志并写入一条重置记录。

#### 场景: 开发与正式隔离

- **WHEN** 开发版与正式版先后运行
- **THEN** 两者日志分别位于不同目录

#### 场景: 重置应用

- **WHEN** 用户重置应用
- **THEN** 原有日志被清空，新日志第一条为重置记录

### 需求: Web 端仅内存记录

Web 端 SHALL 以内存保存最近约 2000 条记录供反馈附带，MUST NOT 持久化到浏览器存储。

#### 场景: 刷新后清空

- **GIVEN** Web 端已有若干记录
- **WHEN** 用户刷新页面
- **THEN** 记录被清空，从新的环境快照开始
