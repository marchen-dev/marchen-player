# 实现验证（尚未人工验收）

## 范围与实现

- Electron 在受控媒体租约中缓存完整识别前缀：单来源最多 16 MiB，全局缓存预算 64 MiB，包含正在填充的缓存；预算不足则回退网络读取。
- 缓存只接住识别器的完整前缀请求，不主动下载更多数据。完整命中直接返回；跨边界按反压读取后缀；部分失败不发布缓存。
- 导入完成后加载会话持有基础引用，主播放获取独立引用，所有引用释放后关闭。保留引用支持播放宿主初始化重挂载、直接播放及重试弹幕；取消、切换、销毁释放会话引用。缩略图不能领取识别资源。
- Web 隐藏首页 URL 按钮及实验室选项，阻止旧历史恢复、导入器和底层远程读取，删除 Worker 的 Web 直连远程来源分支。保留本地文件和链接弹幕。
