# 远程内嵌字幕限制回归

## 实现与结果

来源策略统一用于内嵌目录和解析入口，远程在创建资源之前返回空目录或拒绝。UI 保留外挂功能并区分目录、轨道和导入状态；远程内嵌专属字体索引/期限分支及测试已移除，本地字体预算与取消保留。兼容 Worker、网络预读和主进程协议没有本次改动。

受控视频为 H.264/AAC 双音轨 MKV（带 SRT），由原 20 秒样片循环拼成 5 分钟用于交互验证；另用单音轨 MP4 检查双内核切换。不是长时间弱网或所有编码兼容测试。弹幕匹配响应模拟未匹配，音视频及字幕路径实际运行。Chrome DevTools MCP 不可用，使用 Playwright 独立浏览器与 Electron 实例；Electron 文件对话框仅在测试实例中指定真实 SRT 路径。

两端远程初始字幕阶段诊断为空，共用入口测试验证没有创建字幕专用资源。实际媒体请求仍包含音视频必要数据，不能据此声称完全不传输字幕字节。

音轨检测在通向 AudioDestination 的节点旁接 AnalyserNode，不替换解码器或音频数据；仅采集 context running 的非静音波形，测得第一轨约 439 Hz、第二轨约 656–662 Hz。证明不同音轨数据到达音频输出链路，未进行人工扬声器听辨。原始检查数据见 assets/*results.json。内核切换时钟与呈现状态见 assets/*switch.json。

外挂截图观察到实际文字；本地等待字幕画布出现非透明像素后截图，避免把仅选中轨道误写为显示成功。旧内嵌历史降级通过；外挂持久化与目录恢复有自动检查，未在本轮模拟操作系统重启后恢复。初次短样片运行曾在检查完成前播放结束，另有测试脚本传递超大字节数组造成延迟，最终用长样片和浏览器内 Blob 读取重跑；失败尝试不计入通过结果。

## 范围与限制

无设计偏离。旧增量字幕提案及失败证据保留，未自动归档；其他工作区改动未纳入本次成果声明。未验证 Windows、所有真实网盘来源或所有编码，未承诺兼容内核卡顿全部解决。限制仅针对远程内嵌字幕；仅有内嵌字幕的远程番剧需要手动外挂或本地文件。
