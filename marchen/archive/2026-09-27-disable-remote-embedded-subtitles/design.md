## 背景

Electron/Web 的字幕 Port 均通过 `embedded-catalog.ts` 列举、解析内嵌轨道，后者创建独立资源，进入 Matroska 文本和字体读取。外挂导入与恢复在各平台 Port 中独立处理。兼容 Worker 的音视频读取、解码不依赖该字幕目录，因而无需禁用兼容内核。

当前工作区已含 HTTP 播放、远程字体索引及字幕取消等改动。实施时核对引用并保留其他工作，不回滚完整文件。`load-remote-subtitles-on-demand` 仅完成基线与实验，未接入生产增量链路；本变更采用新的能力限制，不依赖其剩余任务。

## 目标与非目标

**目标：** 在统一字幕入口阻止远程内嵌读取，UI 明确能力边界；保留远程兼容播放和音轨、本地字幕、外挂字幕及历史恢复。

**非目标：** 槽位池、增量字幕、全局缓存、解码/音频队列重构、数据库迁移、依赖修改或远程字幕服务。不承诺解决全部兼容播放卡顿，也不要求音视频请求避开所有含字幕的文件字节。

## 决策

### 1. 集中表达字幕来源能力

在共用字幕服务/平台边界提供一个小型来源能力判断，输入 DurableMediaSource，表达是否允许内嵌字幕。远程一律不允许；本地沿用原容器及编码支持判断。不要把整个 subtitles Port 设为不可用，否则会误伤外挂功能；也不向各层散落 remote 判定。

`listEmbeddedSubtitles()` 在创建 resource 或读取 magic 前返回空列表，`resolveEmbeddedTrack()` 在创建 resource 前拒绝远程请求。两者共用上述策略，分别防止正常目录路径和旧轨道直接解析路径绕过。平台列表继续合并合法外挂目录，Electron 远程来源仍不扫描本地相邻文件。

```text
远程 URL ── 原有媒体资源 ── H5 / 兼容 Worker ── 视频、音轨
      └── 字幕 Port ── 内嵌入口：目录为空、解析拒绝
                     └ 外挂导入/恢复 ── 原有 libass 完整文本路径
本地文件 ── 原有内嵌/外挂字幕路径
```

兼容 Worker、源资源 owner、原生协议流式响应和网络预读保持既有行为；只在回归确认确实有相关缺陷时另行讨论，不把字幕限制扩成性能重构。

### 2. 字幕状态与历史选择

字幕 Context 向 UI 暴露来源能力，复用入口判断结果。目录为空正常完成初始化，不制造字幕失败或长时间 loading。旧远程内嵌 history tags 留存但不能生成可选内嵌轨道，默认 ID 没有对应合法轨道时按既有外挂首选规则处理；无外挂则关闭。明确 defaultId=-1 保持关闭。外挂路径/文本恢复失败沿用现有提示，不误报为内嵌限制。

不清空 history.subtitles、不改 schema、不覆盖用户设置；字幕时间偏移、字号、外挂标签和持久化预算保持现状。切源和恢复继续使用原有取消及代次保护，旧本地目录或旧画面不得残留到远程会话。

### 3. UI 只展示能力与真实操作状态

远程字幕面板显示“远程视频暂不支持内嵌字幕”，保留关闭选项、可用外挂列表、导入按钮、字号和偏移。隐藏针对内嵌目录的“重新读取轨道”和读取等待；不无条件隐藏所有 loading/error，外挂导入和恢复的实际状态仍可见且可恢复。文案不附加协议细节，不增加新开关。

### 4. 清理限于失去调用方的专属代码

入口限制后核对远程字体索引/超时分支、remote 参数和相关测试的实际调用。确定仅为远程内嵌服务且已无调用方时随本变更移除或收敛；仍用于本地或其他功能的解析、字体预算、取消和诊断保留。不全盘回滚之前的 HTTP 修复，不移除原生/兼容网络预读。旧实验脚本和 evidence 保留为历史证据，不列为本功能通过门槛。

### 5. 验证边界

核心测试观察共用字幕入口：远程目录为空、旧轨道解析拒绝，且 create resource/read/字体提取不被调用。这里验证的是字幕专用路径的零读取，不通过“服务器没有任何网络请求”作错误断言。

补充远程旧内嵌默认值、明确关闭、外挂恢复及本地/远程交替的回归。使用含内嵌字幕和多个可区分音轨的受控远程样片，在 Electron 和 Web 桌面观察实际兼容画面推进、声音及换轨、seek/倍速；支持双内核的样片验证切换后仍正常。导入真实外挂并观察文字、字号/偏移，再验证本地内嵌显示。真实 URL 可补充回归，但 CORS 或源失效不能被宣称为双端已通过。

运行相关 runtime 测试、双端 typecheck、定向 lint、Electron/Web 构建；仅在实际触及 main 时扩展对应测试。按 apply 收尾时配置决定是否进入人工验收流程，生成本变更证据，不修改原变更签核。

## 风险与权衡

- 仅有内嵌字幕的远程番剧将无字幕，需要用户手动提供外挂或使用本地文件；明确提示此能力限制。
- 只隐藏 UI 不足以阻止历史或旧描述触发解析，因此必须同时限制目录和解析入口。
- 若错误地关闭整个字幕 Port，会破坏外挂功能；若按内核而非来源判断，会错误限制兼容内核。
- 移除专属远程优化时容易误删共用本地能力，必须以引用分析及本地回归为依据。
- 旧增量提案仍作为记录存在，当前实施依据为本变更；不在 propose 中暗改旧文档、重写失败证据或自动归档。
