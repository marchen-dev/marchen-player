## 目的

统一文件导入的容错、统计、大小策略和来源一致性，保留现有 B 站 XML / JSON 格式范围。

### 需求: 解除固定文件大小门槛

系统 MUST 移除 10 MB 导入限制及对应提示，不以新的固定大小阈值替代；实际读取或存储失败 SHALL 给出可理解的错误。

#### 场景: 大于 10 MB 的合法文件

- **GIVEN** 一个超过 10 MB、格式正确的弹幕文件且设备资源足够
- **WHEN** 用户导入文件
- **THEN** 系统处理并保存有效弹幕，不因超过原大小门槛拒绝

### 需求: 单条容错与模式支持

系统 SHALL 逐条校验并跳过无效条目。模式 1、2、3 按普通滚动处理，4 按底部、5 按顶部处理；6 至 9 及其他模式 SHALL 跳过，不把特殊弹幕内容作为普通文本显示。单条无效包括错误时间、颜色、文本或条目结构；现有 JSON 字段与默认值语义 SHALL 保持。

#### 场景: 有效和坏条目混合

- **GIVEN** 文件整体格式正确，包含有效条目、无效条目和不支持的模式
- **WHEN** 用户导入
- **THEN** 仅保存有效且支持的条目
- **AND** 提示“已导入 X 条弹幕，跳过 Y 条无效或不支持的弹幕”，同一条目最多计一次跳过

#### 场景: 全部有效

- **WHEN** 用户导入所有条目均有效的文件
- **THEN** 提示“已导入 X 条弹幕”，不显示零条跳过

### 需求: 文件级错误仍拒绝

系统 MUST 拒绝 XML / JSON 整体语法损坏、不符合既有顶层结构或不支持扩展名的文件。零有效条目 MUST 提示“文件中没有可导入的弹幕”，不得保存空来源。XML 元信息节点不作为弹幕条目或跳过数量。

#### 场景: 整体损坏或结构不符

- **WHEN** 导入损坏的 XML / JSON、非 i 根节点 XML 或非数组 JSON
- **THEN** 提示格式错误，不保存部分来源

#### 场景: 空文件结构或全部跳过

- **WHEN** 合法结构中没有有效且支持的弹幕
- **THEN** 提示没有可导入的弹幕，已有来源不变

### 需求: 来源去重与失败处理一致

系统 MUST 按原始文本内容识别重复来源，同内容改名不得重复追加，同名不同内容允许共存。非预期读取与保存失败 SHALL 经过统一遥测边界；取消、过期会话、重复来源和预期格式校验拒绝不得当作异常上报。

#### 场景: 重复导入

- **GIVEN** 当前视频已有相同文本内容的来源
- **WHEN** 用户从另一个入口选择改名后的同内容文件
- **THEN** 提示“已经添加过该来源”，不重复保存

#### 场景: 存储失败

- **WHEN** 保存发生存储配额等外部错误
- **THEN** 不显示成功、不将未保存来源加入播放，允许重试
- **AND** 使用稳定错误原因记录异常，避免重复上报
