## 目的

让用户在匹配弹窗直接发现并使用本地弹幕，覆盖初次加载和播放中重新选择。

### 需求: 可发现的文件入口

系统 SHALL 在弹窗显示“选择弹幕”、说明“搜索在线弹幕库，或导入自己的弹幕文件”，并在候选列表外固定显示“导入弹幕文件”及“支持 B 站 XML / JSON 格式”。加载阶段 SHALL 保留“稍后选择”。

#### 场景: 候选很多或为空

- **GIVEN** Electron 或 Web 桌面端打开匹配弹窗
- **WHEN** 候选列表滚动或搜索没有结果
- **THEN** 导入入口和格式说明仍可见且可操作
- **AND** 搜索与在线选集原有功能仍然可用

### 需求: 等待匹配时导入开播

系统 MUST 在有效弹幕成功保存后关闭匹配弹窗并进入播放，无需选择在线作品，不将本地来源标记成在线匹配成功。

#### 场景: 首次导入成功

- **GIVEN** 视频正在等待用户选择弹幕
- **WHEN** 用户导入含有效条目的文件且保存成功
- **THEN** 播放使用该本地弹幕来源并展示导入数量
- **AND** 再次打开该视频可恢复已保存来源，不要求原弹幕文件存在
- **AND** 不额外发起在线匹配或弹幕下载来覆盖本地选择

### 需求: 取消和失败可恢复

系统 MUST 在取消文件选择、解析失败或保存失败时保留弹窗及搜索结果，不提前开播；处理期间 MUST 防止重复提交及相互冲突的选集操作。

#### 场景: 用户取消选择或选择坏文件

- **GIVEN** 用户已经输入搜索词并看到结果
- **WHEN** 取消文件选择，或文件无法导入
- **THEN** 搜索词与结果保留，允许重新选择同一个文件
- **AND** 失败显示原因，取消不显示错误

#### 场景: 导入期间切换视频或关闭弹窗

- **GIVEN** 当前视频正在读取或保存弹幕
- **WHEN** 用户切换视频或关闭当前弹窗
- **THEN** 过期操作不得为新视频提交数据、启动播放或展示成功提示

### 需求: 播放中保持上下文

系统 SHALL 在播放中的匹配弹窗和原弹幕设置入口提供一致的文件导入行为，追加来源且保持视频播放进度与原有匹配信息。

#### 场景: 播放中添加本地来源

- **GIVEN** 当前视频已有弹幕来源和播放进度
- **WHEN** 从任一入口成功导入本地文件
- **THEN** 追加并启用该来源，保留已有来源及其选中状态
- **AND** 不重新加载视频；从匹配弹窗导入成功时关闭弹窗
