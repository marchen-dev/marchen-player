## 背景

加载界面在常见窗口尺寸下显得偏小：标题与副标题同为 14px，层级只靠字重和颜色区分，进度条仅 4px × 360px，大窗口里视觉很轻。远程导入时副标题显示 `x MiB / 16.0 MiB`，以副标题文本作为 AnimatePresence 的 key，进度每 250ms 更新一次，而一次切换动画（淡出 180ms + 淡入 180ms）比更新间隔还长，导致副标题持续闪烁；另外分母是 16MiB 识别前缀而非文件大小，容易被误解为视频只有 16MB。

方案：
- 拉开层级（方案 B）：标题放大到 18px 并加粗，进度条加粗到 6px、固定 320px 宽（略宽于常见副标题，不随窗口伸缩，否则大窗口下显得空长），副标题保持 14px；文字列与失败操作区仍为 max-w-md，不与进度条宽度绑定。
- 副标题按种类（读取进度 / 文件名 / 作品集名 / 失败说明）作为动画 key，同一种类内文本原地更新，只在种类切换时淡入淡出。
- 读取进度改为「已读取识别片段 N%」，不再展示 16MiB 分母。
