## 目的

为播放器提供唯一的右侧设置侧栏，使所有设置入口共享连续、可预测且能力驱动的导航与关闭行为。

### 需求: 单一设置侧栏

系统 SHALL 使用同一个右侧侧栏承载所有播放器设置，不得在不同设置面板之间通过关闭后重新打开的方式跳转。

#### 场景: 从设置按钮打开

- **GIVEN** Electron 或 Web 桌面端正在播放视频
- **WHEN** 用户点击播放器设置按钮
- **THEN** 系统打开唯一的播放器设置侧栏
- **AND** 默认显示“播放”标签内容

#### 场景: 在标签之间切换

- **GIVEN** 播放器设置侧栏已经打开
- **WHEN** 用户切换播放、弹幕、字幕或播放列表标签
- **THEN** 侧栏保持打开并在原位置切换内容
- **AND** 视频会话、播放进度和控制器位置不得被重建或重置

### 需求: 入口定位对应标签

播放器上的内容快捷入口 MUST 打开同一侧栏并直接定位到其对应标签。

#### 场景: 打开弹幕设置

- **GIVEN** 播放器提供弹幕设置入口
- **WHEN** 用户点击弹幕入口
- **THEN** 系统打开统一侧栏并显示“弹幕”标签

#### 场景: 打开字幕或播放列表

- **GIVEN** 当前平台提供字幕或目录播放列表能力
- **WHEN** 用户点击对应入口
- **THEN** 系统打开统一侧栏并显示对应标签
- **AND** 不先显示或关闭其他设置面板

### 需求: 能力驱动的标签可见性

系统 MUST 只显示当前播放会话真实支持的设置标签和操作。

#### 场景: Web 单文件播放

- **GIVEN** Web 播放会话不支持目录播放列表
- **WHEN** 用户打开播放器设置侧栏
- **THEN** 系统隐藏播放列表标签
- **AND** 其余受支持标签保持可用

#### 场景: 能力不可用

- **GIVEN** 当前平台未提供某项播放器能力
- **WHEN** 系统构建设置导航与内容
- **THEN** 系统不显示对应标签或操作
- **AND** 不用禁用但不可操作的假入口占位

### 需求: 关闭与会话边界

系统 SHALL 允许用户关闭设置侧栏，但设置侧栏 MUST NOT 提供“退出当前播放”操作。

#### 场景: 关闭侧栏

- **GIVEN** 设置侧栏已经打开
- **WHEN** 用户执行侧栏关闭、按 Escape 或点击允许关闭的侧栏外区域
- **THEN** 侧栏关闭并把焦点恢复到合理的播放器入口
- **AND** 当前视频继续保持原有播放状态

#### 场景: 查看全部设置

- **GIVEN** 用户浏览任一设置标签
- **WHEN** 用户检查侧栏内的可用操作
- **THEN** 侧栏不得显示“退出当前播放”
- **AND** 退出播放继续由播放器现有关闭入口承担

### 需求: 面板打开期间的播放器交互

设置侧栏打开期间，系统 MUST 保持播放器控制器可见并避免全局快捷键误操作侧栏控件。

#### 场景: 操作设置控件

- **GIVEN** 设置侧栏已经打开且焦点位于其中
- **WHEN** 用户使用键盘操作标签、选择器、开关或按钮
- **THEN** 焦点按可见顺序在侧栏内移动且始终可见
- **AND** 播放器全局 Space、方向键、M、F 等快捷键不得抢占该次输入

#### 场景: 关闭后恢复播放器交互

- **GIVEN** 设置侧栏曾阻止播放器自动隐藏与全局快捷键
- **WHEN** 侧栏关闭
- **THEN** 系统释放可见性锁并恢复播放器快捷键
- **AND** 自动隐藏计时从新的用户活动时点重新开始
