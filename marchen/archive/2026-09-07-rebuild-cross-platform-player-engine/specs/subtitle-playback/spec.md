## 目的

提供 Electron/Web 共用的文本字幕、内嵌字体与播放同步，避免将 Web 限制为外挂字幕。

### 需求: 双端字幕提取与选择

系统 MUST 支持 MKV 内嵌 ASS/SSA 和文本字幕以及外挂 ASS/SSA/SRT/WebVTT；本地字幕处理不得依赖远端上传。

#### 场景: Web 打开内嵌字幕影片

- **GIVEN** 用户选择带 ASS/SSA 字幕的 MKV
- **WHEN** 打开字幕菜单并选择轨道
- **THEN** 展示轨道名称和语言，按正确时间显示字幕并保留样式
- **AND** 处理多个轨道、默认/强制标记、字幕头和编码，不因缺少 Node 而关闭功能

#### 场景: 外挂文本与不支持的图片字幕

- **GIVEN** 用户选择受支持文本字幕，或影片含 PGS/VobSub 图片字幕
- **WHEN** 导入或选择字幕
- **THEN** 文本按相应格式呈现；图片字幕明确标记本次不支持，不当作文本读取
- **AND** 单轨解析失败可关闭或更换字幕，视频继续播放

### 需求: 字体附件与准确布局

系统 SHALL 使用媒体内嵌字体并有安全回退、缓存预算及释放机制；字幕区域 SHALL 对齐视频可见区域。

#### 场景: 特效字幕与内嵌字体

- **GIVEN** 带字体附件、描边和定位效果的 ASS 影片
- **WHEN** 切换引擎、窗口尺寸或画面旋转
- **THEN** 字体与布局按可见画面正确呈现，缺失或损坏字体可回退
- **AND** 切源后旧字体资源不会无限积累

### 需求: 字幕时间与历史恢复

系统 MUST 将字幕与统一媒体时钟同步，支持偏移、暂停、倍速及 seek；偏好恢复不得依赖失效临时地址。

#### 场景: 续播和引擎回退

- **GIVEN** 已选择字幕并设置时间偏移
- **WHEN** seek、回退或重新授权同一媒体
- **THEN** 恢复正确轨道和偏移，暂停时字幕不自行前进
- **AND** 换源不重复叠加旧字幕或重复偏移

### 需求: 稳定的字幕偏好恢复

系统 SHALL 区分内嵌与外挂字幕来源，按媒体和轨道信息恢复选择；外挂字幕可保存预算内内容或可恢复定位，MUST NOT 保存临时 blob URL 作为永久路径。

#### 场景: 新解析器下恢复字幕

- **WHEN** 重新打开影片并恢复字幕偏好
- **THEN** 核对媒体与轨道，不将 FFmpeg 流索引直接解释为新解析器 ID
- **AND** 外挂资源无法恢复时要求重新选择，不影响影片历史和视频播放

#### 场景: 超限附件与预检失败

- **WHEN** Matroska 附件容器累计体积超过 32 MiB，或无法可靠预检其大小
- **THEN** 在读取附件载荷前跳过 MediaBunny 附件查询，回退默认字体并提供非阻断提示
- **AND** 不影响视频/字幕文本播放；预算内仍复用 MediaBunny 读取附件，取消和切源释放字体资源
