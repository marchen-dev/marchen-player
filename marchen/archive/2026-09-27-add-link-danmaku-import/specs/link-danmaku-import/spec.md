## 目的

在 Electron 当前视频的弹幕设置中提供平台无关的链接导入能力，抓取失败和取消不影响视频及已有弹幕。

### 需求: 通用且局部的入口

系统 SHALL 仅在 Electron 弹幕设置的文件导入下方提供“从链接添加弹幕”、视频链接与添加操作；进度、取消和重试 MUST 在同一区域展示，输入与按钮不得绑定平台名称。

#### 场景: 在当前视频添加

- **GIVEN** Electron 已打开可播放的视频
- **WHEN** 用户进入弹幕设置
- **THEN** 用户能输入链接并添加弹幕，新来源以 0 秒偏移导入
- **AND** 不新增页面、弹窗、首页按钮或其他入口

#### 场景: Web 与未就绪视频

- **WHEN** 用户使用 Web，或当前没有可接收弹幕的视频
- **THEN** Web 不显示链接入口，未就绪视频不得启动导入
- **AND** 既有文件导入行为不变

#### 场景: 输入校验

- **WHEN** 链接为空，或提交的链接格式错误、不受支持
- **THEN** 链接为空时添加操作不可用；其余错误在链接区域内联展示
- **AND** 不出现浏览器原生表单校验提示

### 需求: 链接识别与有界抓取

系统 SHALL 自动识别受支持平台，首版支持优酷标准播放页及含 vid 的链接，忽略跟踪参数；不支持链接 MUST 在发起抓取前提示。系统 MUST 动态获取当前视频信息，有限重试网络错误，并在风控、令牌失效或响应异常时明确停止，不读取账号 Cookie 或绕过验证。

#### 场景: 有效链接

- **WHEN** 用户提交受支持的链接
- **THEN** 显示标题和已完成/总分段进度，并允许取消
- **AND** 只读取此视频的弹幕，不下载视频或扩展到整部剧

#### 场景: 分段失败或空数据

- **WHEN** 某一分段在有限重试后失败，或所有分段完成但没有有效弹幕
- **THEN** 显示对应错误或无弹幕状态，不生成成功来源
- **AND** 不把失败分段计作零条或完整成功，用户可显式重试

### 需求: 完整提交与播放连续性

系统 SHALL 在全部预期分段成功、转换校验完成后一次添加；保留时间、文字及 RGB 颜色，首版按滚动弹幕显示，报告无效记录跳过数量。系统 MUST 不重载或暂停视频，不覆盖原有来源，不承诺全部历史数据或自动对齐。

#### 场景: 播放中完成导入

- **GIVEN** 视频正在播放并已有弹幕
- **WHEN** 全部分段抓取及有效数据转换完成
- **THEN** 新来源被选中并从当前播放位置参与显示
- **AND** 播放进度、暂停状态和其他来源保持不变

### 需求: 操作与媒体会话隔离

系统 MUST 隔离不同窗口及媒体会话的导入任务，同一窗口最多一个活动抓取；取消、切换视频、关闭播放或销毁窗口时停止对应任务，任何迟到结果不得写入新视频。

#### 场景: 抓取中切换视频

- **GIVEN** 视频 A 的导入正在运行
- **WHEN** 用户切换到视频 B 或关闭播放
- **THEN** A 的任务停止，迟到进度和结果被忽略
- **AND** A、B 的历史弹幕不因该取消任务发生写入

#### 场景: 面板关闭与重复操作

- **WHEN** 用户仅收起设置面板或重复点击添加
- **THEN** 已启动任务继续且不会重复创建；再次打开面板可查看进度或取消
- **AND** 完成后仍须核对媒体会话再写入
