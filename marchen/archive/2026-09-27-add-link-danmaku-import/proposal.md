## 动机

用户希望在播放本地或远程视频时，粘贴视频平台页面链接，将对应弹幕添加到当前视频。现有文件导入需要先手动下载 XML；自动匹配也不能覆盖用户指定的任意链接。首版仅支持 Electron，界面保持平台无关，后续通过新增适配器扩展平台。

此前用用户提供的优酷链接实测识别《甄嬛传 07》，46/46 分段成功、导出 16429 条，未使用账号登录。这证明当前抓取协议可用，不代表 TypeScript 移植、Electron 接入或全部历史弹幕覆盖已验证。

## 变更内容

- 仅在现有弹幕设置、文件导入下方增加“从链接添加弹幕”：视频链接与添加按钮；新来源以 0 秒偏移导入，添加后在同一区域调整偏移；进度、取消、重试在同一区域呈现，不新增页面、弹窗或其他入口。
- 通用链接解析与平台适配契约，首个适配器实现优酷；主进程负责匿名请求、临时令牌及有限重试，不要求 Python、账号 Cookie 或下载视频。
- 全部分段成功后一次添加到当前视频；不暂停或重载视频，失败不覆盖已有弹幕，切换视频后取消并丢弃迟到结果。
- 新增链接弹幕来源，保存规范化身份、标题、原始弹幕及独立时间偏移；支持已有来源勾选、重复识别、重新打开恢复，重新匹配弹弹play时保留链接来源。
- Web 隐藏新增入口，保留现有文件导入和播放行为；本轮不建设后端抓取服务。
- 首版只保证普通滚动弹幕的时间、文字和 RGB 颜色；不做自动对齐、批量整剧抓取、持续刷新或平台特效还原。

## 能力

### 新增能力

- `link-danmaku-import`：Electron 通用链接入口、适配器获取、进度取消与会话隔离。
- `linked-danmaku-source`：链接来源身份、合并选择、时间偏移、持久化与旧数据兼容。

### 修改能力

无独立既有规范需要修订；既有来源保留和重新匹配行为的扩展纳入上述新增能力，文件导入和自动匹配继续回归验证。

## 影响范围

- `src/main/`：抓取服务、优酷适配器、受控 IPC 与请求任务生命周期。
- `packages/shared/`、`packages/player-loading/`：跨进程契约、来源联合类型、来源写入与合并规则。
- Renderer 弹幕设置、来源展示、HISTORY 类型及加载缓存：链接入口、偏移、恢复与热更新。
- 复用当前弹幕引擎和 Electron IPC，不改播放器内核或字幕链路，不引入 Python 运行依赖。
- 与工作区 HTTP 直链、远程字幕和 SEO 改动共存；提交与验收只覆盖本变更文件范围。
