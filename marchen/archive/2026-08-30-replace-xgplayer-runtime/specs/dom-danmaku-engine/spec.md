## 目的

提供与 React 和具体播放器解耦的 DOM 弹幕能力，保证弹幕按媒体时钟正确出现，并在高密度、seek 和 resize 场景下稳定运行。

### 需求: 标准弹幕渲染

系统 SHALL 接收标准化弹幕数据，并按时间、模式、颜色、字号和持续时间渲染滚动、顶部和底部弹幕。

#### 场景: 到达弹幕时间

- **GIVEN** 播放时钟正在前进且存在即将到达的弹幕
- **WHEN** 当前时间越过弹幕时间点
- **THEN** 系统按弹幕模式分配合法轨道并显示内容
- **AND** 弹幕不得进入配置禁止的显示区域

### 需求: 播放时钟同步

弹幕 MUST 与视频的播放、暂停、seek 和倍速保持同步，不得依赖 React 逐帧重渲染。

#### 场景: 暂停与恢复

- **GIVEN** 屏幕中存在运动弹幕
- **WHEN** 视频暂停后再次播放
- **THEN** 弹幕在暂停期间保持位置并在恢复后继续运动

#### 场景: Seek 到新时间

- **GIVEN** 弹幕引擎正在运行
- **WHEN** 播放时间跳转到另一个位置
- **THEN** 系统清理不再有效的在屏弹幕并从新时间建立调度窗口
- **AND** 不重复补发已经越过显示窗口的弹幕

### 需求: 轨道与高密度控制

系统 MUST 检测滚动弹幕碰撞，并对节点数量和同时在屏弹幕设置明确上限。

#### 场景: 没有安全轨道

- **GIVEN** 所有允许轨道都无法安全容纳新弹幕
- **WHEN** 新弹幕到达
- **THEN** 系统按配置的丢弃策略跳过弹幕而不是无限创建节点或产生严重重叠

#### 场景: 节点复用

- **GIVEN** 一条弹幕完成显示
- **WHEN** 后续弹幕需要创建元素
- **THEN** 系统优先复用可用节点
- **AND** 复用节点不得残留上一条弹幕的文本、样式或状态

### 需求: 动态更新

系统 SHALL 在不重建播放会话的情况下应用弹幕来源、显示开关、字号、区域、持续时间和密度设置变化。

#### 场景: 重新匹配弹幕源

- **GIVEN** 视频正在播放且用户完成重新匹配
- **WHEN** 新弹幕集合到达
- **THEN** 引擎切换到新数据并从当前媒体时间继续调度
- **AND** 视频播放不中断

#### 场景: Resize

- **GIVEN** 播放器尺寸发生变化
- **WHEN** 新尺寸稳定
- **THEN** 引擎重新计算轨道与可用区域
- **AND** 后续弹幕使用新布局约束

### 需求: 交互和遮挡

弹幕 SHOULD 支持 hover 暂停，并 MUST 避免把需要阅读的固定弹幕放在可见控制器的遮挡区域中。

#### 场景: 控制器遮挡区域变化

- **GIVEN** 可拖动控制器处于显示状态
- **WHEN** 控制器移动或显隐
- **THEN** 引擎更新遮挡区域
- **AND** 新分配的固定弹幕不得落入该区域
