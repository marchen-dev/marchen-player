## 目的

通过明确的平台能力向共用播放器暴露 Electron 与 Web 的差异，使界面按能力工作而不是直接判断运行平台。

### 需求: 能力驱动界面

系统 SHALL 为当前运行环境提供稳定的能力集合，界面 MUST 只展示或启用受支持的操作。

#### 场景: Web 单文件播放

- **GIVEN** 播放器运行在 Web 且没有目录播放列表能力
- **WHEN** 控制器渲染传输操作
- **THEN** 系统显示前后跳转时间操作而不是不可用的上下集操作
- **AND** 不显示内嵌字幕、截图或窗口全屏能力

#### 场景: Electron 目录播放

- **GIVEN** 当前视频所在目录存在可播放文件
- **WHEN** 播放器运行在 Electron
- **THEN** 播放列表和上下集操作可用
- **AND** 文件读取失败时降级为只播放当前文件

### 需求: 全屏适配

系统 MUST 分别适配 Web DOM 全屏与 Electron 窗口全屏，并保持播放状态、控制器和浮层同步。

#### 场景: Web 进入全屏

- **GIVEN** 浏览器允许用户触发 Fullscreen API
- **WHEN** 用户请求全屏
- **THEN** 整个播放器根节点进入全屏
- **AND** 设置、菜单和 Tooltip 仍在全屏元素内部可见

#### 场景: 外部退出全屏

- **GIVEN** 播放器处于全屏
- **WHEN** 用户按 Escape 或系统结束全屏
- **THEN** 播放器根据平台全屏事件同步界面状态
- **AND** 不重复发送相反的全屏命令

### 需求: Web 文件生命周期与兼容错误

Web MUST 管理本地文件产生的临时 URL，并在浏览器不能播放编码时提供明确降级。

#### 场景: 换片回收 URL

- **GIVEN** 当前 Web 视频使用本地 Object URL
- **WHEN** 用户换片或退出播放器
- **THEN** 系统撤销旧 URL
- **AND** 不撤销仍被当前会话使用的 URL

#### 场景: Web 不支持媒体编码

- **GIVEN** 浏览器无法解码所选视频
- **WHEN** 媒体加载报告不支持或解码错误
- **THEN** 系统说明当前 Web 能力限制并提供桌面版入口
- **AND** 不上传视频或自动启动 FFmpeg WASM 转码
