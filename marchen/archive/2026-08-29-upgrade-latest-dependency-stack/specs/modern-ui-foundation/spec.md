## 目的

在最新 React UI 基础栈上维持现有页面、导航、弹层、动画、主题和响应式表现，为后续 UI 重构提供稳定基线。

### 需求: 保持页面导航行为

升级后的路由层 MUST 保持播放器与影视库路由、默认重定向以及 Web 端路由过滤行为。

#### 场景: Electron 端导航

- **GIVEN** 应用运行于 Electron
- **WHEN** 用户在播放器和影视库之间切换
- **THEN** 对应页面 MUST 正常渲染
- **AND** 页面标题与导航激活状态 MUST 同步更新

#### 场景: Web 端访问影视库

- **GIVEN** 应用运行于 Web 环境
- **WHEN** 用户直接访问影视库路由
- **THEN** 应用 MUST 重定向到播放器
- **AND** 导航中不得展示影视库入口

### 需求: 保持弹层与动画行为

升级后的动画和组件基础设施 MUST 保持 Modal Stack、Dialog、Sheet、Popover、菜单及页面过渡的交互语义。

#### 场景: 打开并关闭堆叠弹层

- **GIVEN** 页面可触发一个或多个弹层
- **WHEN** 用户依次打开、拖动和关闭弹层
- **THEN** 遮罩、层级、焦点与退出动画 MUST 正常工作
- **AND** 关闭上层弹层不得破坏下层弹层状态

### 需求: 保持主题与样式结果

升级后的样式链 MUST 在亮色和暗色主题下生成现有 Tailwind utility、主题 token 和组件状态样式。

#### 场景: 切换主题

- **GIVEN** 播放器页和影视库页均可访问
- **WHEN** 用户在亮色与暗色主题间切换
- **THEN** 页面、弹层和基础控件 MUST 使用正确的主题 token
- **AND** 不得出现大面积未生成样式或不可读文本
