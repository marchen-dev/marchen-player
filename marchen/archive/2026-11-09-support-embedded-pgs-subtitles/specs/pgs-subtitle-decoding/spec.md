## 目的

把 MKV 字幕块中的 PGS 显示集还原为位置确定、颜色正确的字幕位图，并正确处理显示集之间的依赖关系。

### 需求: 解析显示集

系统 SHALL 把每个 PGS 字幕块（按轨道内容编码解压后）解析为一个显示集，包括合成信息（画布尺寸、合成状态、合成对象及其位置）、窗口定义、调色板定义和对象定义。分片的对象定义（首片 / 末片标志）MUST 拼接完整后再解码。段长度越界、对象分片不完整或缺少合成信息的显示集 MUST 被判为损坏，不得产出部分位图。

#### 场景: 单对象显示集

- **GIVEN** 一个字幕块包含合成、窗口、调色板、一个完整对象定义和结束段
- **WHEN** 解析并解码该块
- **THEN** 产出一张位图，其位置等于合成对象坐标，尺寸等于对象宽高
- **AND** 画布尺寸等于合成信息中的宽高（例如 1920×1080）

#### 场景: 分片对象

- **GIVEN** 一个对象定义被拆成首片和末片两段
- **WHEN** 解析该显示集
- **THEN** 两段数据拼接后解码，位图与未分片时的结果一致

#### 场景: 清屏显示集

- **GIVEN** 一个显示集的合成对象数为 0
- **WHEN** 解析该显示集
- **THEN** 结果表示“此刻起不显示字幕”，不产出位图

#### 场景: 损坏的显示集

- **GIVEN** 一个字幕块的段长度超出块数据范围
- **WHEN** 解析该块
- **THEN** 该显示集被判为损坏，返回稳定原因码，不产出任何位图

### 需求: 显示集依赖与 epoch

合成状态为 Normal 的显示集可以沿用同一 epoch 中之前显示集定义的窗口、调色板和对象。系统 MUST 从最近一个合成状态为 Epoch Start 或 Acquisition Point 的显示集开始累积这些定义，再解码目标显示集；后出现的同 ID 定义 MUST 覆盖先前的定义。目标显示集引用的对象或调色板在累积范围内找不到时，该显示集 MUST 被判为不可显示，不得用错误的调色板或空对象替代。

#### 场景: Normal 显示集引用前一个显示集的对象

- **GIVEN** 显示集 A 为 Acquisition Point，定义了对象 1 和调色板 0；紧随其后的显示集 B 为 Normal，只更新了合成位置
- **WHEN** 解码 B
- **THEN** B 使用 A 中的对象 1 和调色板 0，在新位置显示

#### 场景: 后定义覆盖先定义

- **GIVEN** 同一 epoch 内调色板 0 先后被定义两次
- **WHEN** 解码引用调色板 0 的后续显示集
- **THEN** 使用第二次定义的颜色

#### 场景: 依赖缺失

- **GIVEN** 一个 Normal 显示集引用的对象在 epoch 起点之后从未定义
- **WHEN** 解码该显示集
- **THEN** 判为不可显示，返回稳定原因码

### 需求: RLE 解码与调色板换算

系统 SHALL 按 PGS 行程编码规则把对象数据还原为调色板索引。解码结果的像素数与对象宽高不一致时 MUST 判为损坏。调色板中的 YCbCr 与透明度 MUST 换算为预乘前的 RGBA；未在调色板中定义的索引 MUST 视为完全透明。

#### 场景: 行程编码还原

- **GIVEN** 一个 4×2 对象的 RLE 数据包含单像素、短行程、长行程和行结束标记
- **WHEN** 解码
- **THEN** 得到的 8 个索引与编码前一致

#### 场景: 像素数不符

- **GIVEN** RLE 数据还原出的像素数少于对象宽高之积
- **WHEN** 解码
- **THEN** 判为损坏，不产出位图

#### 场景: 未定义的调色板索引

- **GIVEN** 对象引用了调色板中没有定义的索引
- **WHEN** 换算颜色
- **THEN** 这些像素完全透明

### 需求: HDR 视频的颜色换算

系统 SHALL 对所有视频按 BT.709 limited range 换算 PGS 调色板。视频的传递函数为 PQ 或 HLG 时，系统 SHALL 在此基础上统一提亮，使字幕主体亮度在 SDR 输出下与 mpv 的基准结果一致（误差不超过 ±3 级 / 255）；提亮 MUST NOT 改变透明度，超出范围的颜色裁剪为白色。

#### 场景: UHD HDR 原盘字幕亮度与 mpv 一致

- **GIVEN** 视频传递函数为 PQ，调色板中字幕主体颜色为 Y=154、Cb=128、Cr=127（limited range）
- **WHEN** 换算颜色
- **THEN** 字幕主体的 RGB 分量约为 178 / 255（mpv 在 SDR 输出下实测为 175–180），而不是未提亮时的约 161

#### 场景: HDR 视频的亮色裁剪

- **GIVEN** 视频传递函数为 PQ，调色板中有一项 Y=235、Cb=Cr=128、透明度 128
- **WHEN** 换算颜色
- **THEN** 结果为白色，透明度仍为 128

#### 场景: SDR 视频保持 BT.709

- **GIVEN** 视频传递函数为 BT.709 或未知，调色板白色为 Y=235、Cb=Cr=128
- **WHEN** 换算颜色
- **THEN** 结果为白色
