## 目的

提供不依赖第三方播放器实例的基础播放会话，使 Electron 与 Web 可以通过同一组状态和命令控制浏览器原生可播放的视频。

### 需求: 播放会话生命周期

系统 SHALL 为每个已准备的视频创建唯一播放会话，并在换片、退出播放器或组件销毁时释放旧会话的全部监听与资源。

#### 场景: 加载准备完成的视频

- **GIVEN** 视频导入、匹配和弹幕加载已经完成
- **WHEN** 播放器接收准备完成的视频来源
- **THEN** 系统创建新的播放会话并进入媒体加载状态
- **AND** metadata 可用后公开时长、可播放状态和初始进度

#### 场景: 切换视频

- **GIVEN** 当前已有播放会话
- **WHEN** 用户加载另一个视频
- **THEN** 系统先停止并销毁旧会话，再创建新会话
- **AND** 旧视频的事件不得继续修改新会话状态

### 需求: 基础播放控制

系统 MUST 支持播放、暂停、时间跳转、音量、静音和倍速，并向界面提供一致的当前状态。

#### 场景: 拖动进度

- **GIVEN** 视频已经获得有效时长
- **WHEN** 用户把时间轴拖到目标时间
- **THEN** 播放位置更新到合法范围内的目标时间
- **AND** 拖动结束后恢复拖动前应有的播放或暂停状态

#### 场景: 修改播放倍速

- **GIVEN** 播放会话已创建
- **WHEN** 用户选择受支持的倍速
- **THEN** 视频按所选倍速播放
- **AND** 播放状态向弹幕和字幕同步该变化

### 需求: 媒体事件与错误

系统 SHALL 把加载、可播放、播放、暂停、时间变化、seek、结束和错误映射为稳定的播放状态。

#### 场景: 自动播放被浏览器阻止

- **GIVEN** 视频准备完成且配置允许自动播放
- **WHEN** 浏览器拒绝自动播放请求
- **THEN** 系统保持可交互的暂停状态而不是进入错误状态
- **AND** 用户点击播放后可以继续播放

#### 场景: 媒体解码失败

- **GIVEN** 浏览器不能播放当前媒体来源
- **WHEN** video 元素报告不可恢复的媒体错误
- **THEN** 系统显示可理解的兼容性错误
- **AND** 错误状态可被辅助技术获知且允许用户退出或换片
