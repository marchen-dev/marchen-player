## 目的

将完整下载文件衔接现有本地播放及数据管理。

### 需求: 单集播放与延迟入库

系统 MUST 仅允许已完整校验的受支持视频播放，下载完成不得自动入库。

#### 场景: 单集播放与延迟入库的可观察结果

- **GIVEN** 合集一集完成而其他集未完成
- **WHEN** 点击该集播放
- **THEN** 调用现有本地播放流程；形成历史并按匹配结果关联影视库，不批量关联其他文件

### 需求: 播放列表过滤

系统 MUST 从受下载管理文件的播放列表中排除未完成或失效视频。

#### 场景: 播放列表过滤的可观察结果

- **GIVEN** 目录含完成与未完成视频
- **WHEN** 从下载页、系统视频入口或历史打开视频
- **THEN** 下一集只列可用完成文件；已有普通本地视频行为保持

### 需求: 字幕与历史

系统 SHALL 保留目录结构并复用既有字幕、音轨、弹幕和续播规则。

#### 场景: 字幕与历史的可观察结果

- **GIVEN** 视频及匹配命名的附件完成
- **WHEN** 播放或再次播放该视频
- **THEN** 按现有能力发现字幕并恢复进度，不用 torrent 标识代替视频匹配 hash

### 需求: 删除边界

系统 MUST 默认删除任务时保留文件，仅显式选择同时删除时删除任务拥有的文件。

#### 场景: 删除边界的可观察结果

- **GIVEN** 用户删除任务
- **WHEN** 确认删除
- **THEN** 保留文件时历史仍可使用；正在播放或其他任务共享的文件阻止物理删除，不递归删除无关文件

### 需求: 退出与清除

系统 MUST 在退出或清除数据前停止传输并按操作持久化或清理任务。

#### 场景: 退出与清除的可观察结果

- **GIVEN** 有运行任务
- **WHEN** 退出应用或确认清除数据
- **THEN** 退出提示后停止并保存任务；清除则停止后清理任务和元数据但保留下载视频；失败时不得宣称清理成功
