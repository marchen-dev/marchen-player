## 目的

将操作系统种子打开动作送入新建下载流程。

### 需求: 系统关联

系统 SHALL 注册 macOS 和 Windows 的 torrent 打开方式，不主动改默认应用。

#### 场景: 系统关联的可观察结果

- **GIVEN** 安装对应平台应用
- **WHEN** 用户选择以 Marchen 打开 torrent
- **THEN** 唤起应用并进入下载确认流程，既有视频关联正常

### 需求: 启动期间排队

系统 MUST 保留多个待打开种子请求并在界面就绪后依次处理。

#### 场景: 启动期间排队的可观察结果

- **GIVEN** 应用未启动、窗口关闭或正在初始化
- **WHEN** 打开一个或多个种子
- **THEN** 创建或恢复窗口，按序展示确认；取消一个不丢失其他请求

### 需求: 任务去重

系统 MUST 按资源标识阻止重复任务。

#### 场景: 任务去重的可观察结果

- **GIVEN** 同一资源已存在或处于待确认队列
- **WHEN** 从不同路径再次打开相同种子
- **THEN** 定位已有任务或合并待确认请求，提示已存在，不覆盖原文件
