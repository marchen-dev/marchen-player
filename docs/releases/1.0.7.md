# Marchen 1.0.7

## Linux

- 恢复 Linux 版本：提供 x64（正式支持）与 arm64（实验性支持），每个架构都有 deb 与 AppImage 两种安装包。
- deb 推荐 Ubuntu / Debian 用户使用：安装后出现在应用菜单，可在文件管理器中右键视频或 `.torrent` 文件"用 Marchen 打开"；在 Ubuntu 24.04 及以上会安装 AppArmor 配置，始终启用沙箱。有新版本时应用会提示并打开下载页，下载新 deb 覆盖安装即可。
- AppImage 适合其他发行版，支持应用内下载并重启更新；Ubuntu 22.04 起需要先安装 FUSE 2。Ubuntu 24.04 上由于系统限制会以无沙箱模式运行。
- arm64 为实验性支持，不保证 Asahi Linux（16K 页内核）与树莓派等低功耗设备上的播放流畅度。
- 大多数 Linux 环境没有 HEVC 硬件解码，HEVC 视频会自动由兼容内核软件解码播放，对 CPU 要求较高。
- 安装步骤与常见问题见 [Linux 安装说明](https://github.com/marchen-dev/marchen-player/blob/main/docs/linux-install.md)。

## 修复

- 修复应用已运行时，从文件管理器再次打开视频不生效的问题（Linux）。
