# Marchen 1.0.0-alpha.2

本次 Alpha 新增桌面端下载功能，并改善远程视频读取提示、弹幕复制与界面体验。

## 下载

- 新增「下载」页面，支持磁力链接、BT 种子和 HTTP/HTTPS 文件直链。
- HTTP 下载支持最多 3 个文件同时下载，其余任务自动排队。
- BT 合集支持选择下载文件，也可在下载过程中增减集数、全选或取消全选。
- 支持暂停、继续、重试、打开目录及查看 BT 节点详情。
- 下载完成后自动停止传输，文件保留在下载列表；首次播放后沿用现有流程进入影视库。
- 新任务按原文件或文件夹名保存，不额外套一层目录；已有任务保留原路径。

## 弹幕与播放

- 点击弹幕即可复制内容，并显示复制成功提示。
- URL 播放与影视库远程播放新增识别数据读取进度。
- 播放设置中显示本地／远程来源，远程视频可查看接收速度及累计接收量。
- 修复通过系统「打开方式」启动视频时未正常播放的问题。

## 界面

- 统一蓝色主题，调整设置与弹窗样式。
- 下载设置移至独立分类，任务更多操作改为下拉菜单。
- 移除尚未接入的 AI 服务设置。

## 使用说明

- 下载功能仅支持桌面客户端。BT 暂仅支持 v1，不支持 v2 或混合种子。
- HTTP 下载支持文件直链，不包含网页视频解析或 m3u8/HLS 下载；断点续传取决于服务器支持，重启应用后需手动继续。
- 视频直链播放仍需在「设置 → 实验室」开启；读取百分比仅表示播放前的识别数据读取进度。
- macOS 支持 macOS 13 及以上的 Apple Silicon（ARM64）；Windows 提供 x64 安装包。
