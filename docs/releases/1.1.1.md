# Marchen 1.1.1

## 加载与弹幕

- 加载界面改为一条连续的进度条，匹配到番剧后显示作品名和集数；加载很快时（如已匹配过的视频）不再闪出加载界面。
- 加载中的「直接播放」改为「先播放，弹幕稍后加载」：视频立即开始播放，未完成的匹配和弹幕在后台继续加载并自动接入；选集弹窗中可点「稍后选择」先播放，之后在弹幕设置中再选剧集。
- 手动指定 API 线路时，弹幕和匹配请求的等待时间更长，服务端响应较慢时不再轻易出现弹幕加载失败。

## 播放

- 控制栏自动隐藏更快，用方向键快进快退时不再唤起控制栏。
- SRT / VTT 字幕遇到个别格式错误的段落时跳过该段继续显示，时间格式不规范的字幕也能正常加载。

## 其他

- 关于页的更新下载进度显示已下载大小、下载速度和剩余时间。
