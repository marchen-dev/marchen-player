# Marchen 1.1.0

## 媒体源

- 新增「媒体源」，可连接 Jellyfin、Emby 和 WebDAV，在应用内浏览目录并直接播放，弹幕自动匹配与本地视频一致。
- 直接读取原文件，不经服务端转码；Jellyfin、Emby 显示海报和剧集信息，只有一季的剧集直接列出单集。
- 同一季或同一目录自动组成播放列表，支持上一集、下一集和自动连播。
- 自动加载服务端字幕或同目录的外挂字幕，字幕选择随播放记录保存。
- 浏览时显示观看进度和「已看完」，可从播放记录和影视库继续观看；服务器离线、登录失效或来源已移除时给出对应提示。
- 播放器首页新增「从媒体源打开」入口。

## 播放

- 通用设置新增「优先播放视频」，默认关闭；开启后导入即开始播放，弹幕在后台匹配和加载后接入，不打断当前进度。
- 「通过 URL 播放」改为默认开启，此前手动关闭过的保持关闭。

## 其他

- 安装包文件名带上系统名称，方便区分不同平台的下载。
- 升级播放相关依赖，提升稳定性。
