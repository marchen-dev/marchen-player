# Marchen 1.0.0-alpha.1

本次 Alpha 更新改善了弹幕加载体验，并新增桌面端视频直链播放和链接弹幕导入。

## 新功能与改进

- 匹配或弹幕加载等待期间可选择“直接播放”，不必等到超时；加载失败后支持重试。
- 新增视频直链播放实验功能：在“设置 → 实验室”开启“通过 URL 播放”后，可从首页打开 HTTP/HTTPS 视频文件链接，支持原生与兼容播放内核。
- 复用识别时已读取的视频前缀，减少起播阶段的重复下载，改善远程视频的首帧等待。
- 桌面端支持通过优酷视频链接添加弹幕，可单独开关来源、调整时间偏移，并保存到播放记录。
- 字幕支持 50%～200% 字号缩放，并自动记住设置。
- 展示当前匹配的番剧与集数，支持快捷开关弹幕。
- 移除字幕设置中容易产生误解的“重新读取轨道”按钮。

## 使用说明

- 视频直链播放仅支持桌面客户端，默认关闭。来源需支持按需读取；暂不支持 m3u8/HLS、网页地址、需要登录或自定义请求头的视频。
- 远程视频暂不支持内嵌字幕，可手动导入外挂字幕；本地视频的内嵌字幕与外挂字幕功能保留。
- 首次识别仍需读取部分视频数据，起播速度受网络、来源服务和视频编码影响。实验功能仍在完善，欢迎反馈问题。
- macOS 支持 macOS 13 及以上的 Apple Silicon（ARM64）；Windows 提供 x64 安装包。
