# Marchen 1.0.6

## 播放

- 新增画中画，可在设置面板「播放偏好」中进入或退出。画中画窗口只显示画面，不含弹幕和字幕；仅原生播放内核支持，兼容内核或浏览器不支持时按钮置灰并说明原因。
- 新增“点击画面暂停/播放”选项，默认关闭；开启后双击仍可切换全屏。
- 设置面板中的“连续播放”分组更名为“播放偏好”。

## 播放列表

- 播放列表按文件名的公共部分分组折叠，组标题显示作品名，条目只显示集号等差异部分；悬停可查看完整文件名，打开列表时自动定位到当前集。
- 打开播放列表和自动续播下一集前会重新扫描剧集，追更期间新下载的剧集可以直接续播。
- 修复拖入单个视频后不显示同目录播放列表的问题。

## 弹幕

- 新增弹幕不透明度设置，对所有视频生效，调整后立即可见，悬停工具条保持清晰。
- 跳转进度后会立即恢复当前时刻应在屏幕上的弹幕，不再等到新弹幕出现；暂停、倍速和连续跳转时同样生效。

## 界面

- 播放控制器和设置面板改用更通透的毛玻璃材质，画面颜色可以透过面板显示。
- 播放器内的下拉菜单、提示气泡、匹配提示、关闭按钮和播放中的通知统一使用同一套毛玻璃材质。
