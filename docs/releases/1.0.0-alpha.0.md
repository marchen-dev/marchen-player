# Marchen 1.0.0-alpha.0

这是重构后的首个 Alpha 测试版本，适合愿意反馈问题的用户。

- 重构播放器运行时，支持原生与兼容播放内核、音轨和字幕处理。
- macOS 接入 Sparkle 中文原生更新窗口，Windows 支持自主下载、安装并重启。
- 更新安装前保存播放进度；支持按安装版本自动选择 Alpha、Beta、稳定更新渠道。
- 打包版支持 F12 打开开发者工具，便于反馈完整错误信息。

## 安装与迁移

- macOS 仅支持 macOS 13 及以上的 Apple Silicon（ARM64）；Windows 提供 x64 安装包。
- Linux 和 Intel Mac 不再提供新版本，历史安装包仍保留。
- 旧 macOS 用户需要手动覆盖安装一次，之后使用 Sparkle 更新。
- macOS 使用 ad-hoc 签名，未经过 Apple 公证，首次打开可能需要在系统“隐私与安全性”中允许。
- 本次数据库重构不迁移旧播放记录，也不会主动删除旧数据。

Alpha 可以接收更新的 Alpha、Beta 和正式版；升级到 Beta 或正式版后，自动按新版本所属渠道检查更新。不会自动降级。
