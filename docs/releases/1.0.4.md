# Marchen 1.0.4

## 弹幕

- 新增弹幕列表，可搜索弹幕内容、按来源筛选，并查看已屏蔽的弹幕。
- 新增弹幕屏蔽，支持关键词、正则表达式和按弹幕类型屏蔽，规则对所有视频生效。
- 悬停弹幕时显示复制、屏蔽工具条，也可直接在弹幕列表中添加屏蔽规则。

## 播放记录

- 播放器首页新增播放记录入口，可查看最近播放的视频，包括未匹配到弹幕的视频。
- 支持继续播放、在文件管理器中显示文件，以及删除播放记录。

## 界面

- 更换应用图标，采用白色底板与青蓝色播放、弹幕元素。
- 播放器内的弹窗和提示统一使用深色色板，改善浅色主题下的观看体验。
- 调整弹幕导入区域的文字行距与输入框间距。
